# 학교 앞 보행로는 정말 안전한가

추정 통학 경로 기반으로 본 어린이보호구역 지정 구간과 보행로의 적합성 (서울 초등학교 565곳)

한겨레 × 숲과나눔 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 분석 코드입니다. 이 저장소만으로 보고서의 수치와 그림 1~3을 다시 만들 수 있습니다.

## 핵심 결과

| 지표 | 값 |
|---|---|
| 현재 지정 구간(정문 보행거리 300m)의 통학 노출 포괄률, 학교 평균 | 45.3% |
| 같은 길이를 노출이 큰 길부터 배치한 대안 | 61.4% (격차 +16.0%p) |
| 500m로 넓혔을 때 (현재 → 대안) | 71.5% → 86.5% |
| 실제 정문 표본 31곳 (현재 → 대안) | 47.8% → 64.8% |
| 사례교 Q3: 지정 구간 안 보도 없음·1.5m 미만 / 30km/h 표시 | 73% / 84% (학생 수 가중) |

## 방법 요약

1. **아동 분포(면적가중 공간 배분):** 집계구 5~9세·10~14세 인구의 각 0.6(인구총조사 기준일 11.1 기준 만 7~12세)을 통학구역에 면적 비율로 배분하고, 학교별 학생 수로 보정합니다.
2. **통학 노출(최단경로 전량 배정):** 학교 위치를 보행 링크에 붙이고, 아동이 최단경로로 등교한다고 가정해 링크별 노출(학생 수 × 길이)을 누적합니다.
3. **포괄률 비교(네트워크 서비스 영역, MCLP형 탐욕 선택):** 정문에서 보행거리 300m 안 링크의 노출 비중(현재)과, 같은 길이를 노출 순으로 채운 비중(대안)을 비교합니다.
4. **검증:** 500m 범위, 대안 연결성, 반대편 보도 중복, 실제 정문 31곳. 보조로 어린이 교통사고 다발지점 위치를 분류합니다(건수만).
5. **사례교 Q3:** 경동·중대·봉천초의 노출 상위 30구간을 로드뷰로 확인한 기록(`q3/q3_coded.csv`)을 학생 수로 가중해 집계합니다.

## 실행 방법

Python 3.10 이상.

```bash
git clone <이 저장소 주소>
cd school-route-safety
python3 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

번호 순서대로 실행합니다(저장소 폴더 안에서). 전체 20~30분.

```bash
python3 src/02_estimate_children.py                 # 집계구 아동 추정 → step2/
python3 src/04_q1_exposure_coverage.py              # 565개교 노출·포괄률 (10~20분)
GATES=q1/gates_hand.gpkg ONLY=q1/hand_names.json OUTP=q1/hand python3 src/04_q1_exposure_coverage.py   # 실제 정문 31곳
python3 src/05_sensitivity_radius_connectivity.py   # 300/500m, 연결성
python3 src/06_check_parallel_links.py              # 반대편 보도 중복
python3 src/07_accident_hotspot_overlay.py          # 사고 다발지점 분류
python3 src/08_fig1_distribution.py                 # 그림 1 → fig/
python3 src/09_fig2_gyeongdong_map.py               # 그림 2 → fig/
python3 src/10_q3_case_schools.py                   # 사례교 3곳(실제 문 위치)
python3 src/11_q3_segments.py                       # Q3 상위 구간 재선정(참고용)
python3 src/12_fig3_cases.py                        # 그림 3 → q3/
python3 src/13_summary.py                           # 보고서 수치 요약 출력
```

`13_summary.py`의 출력이 위 핵심 결과와 같으면 재현된 것입니다.

- **한글 폰트:** 그림 스크립트는 macOS·Windows·Linux의 한글 폰트를 자동으로 찾습니다. 글자가 깨지면 `KFONT` 환경변수에 폰트 파일 경로를 지정합니다.
- **건물 바탕(선택):** 그림 2·3의 건물은 `data/AL_D010_11_20261009.shp`(GIS건물통합정보, 용량 문제로 미포함)가 있을 때만 그립니다.
- **Q3 구간:** 보고서의 30개 구간은 로드뷰로 직접 확인한 구간이라 `q3/segments3.csv`에 고정했습니다. `11_q3_segments.py`는 다시 뽑은 결과를 `q3/segments3_recomputed.csv`에 따로 저장합니다.
- **01·03(선택):** `01_build_network.py`는 도보 네트워크 원자료 CSV로 `net/graph_main.pkl.gz`를 새로 만듭니다(원자료가 갱신되어 노드 수가 조금 다를 수 있음). `03_geocode_vworld.py`는 브이월드 키(`VWORLD_KEY`)가 필요하며 결과는 `gates_final.gpkg`에 반영돼 있습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `src/` | 분석 스크립트 |
| `net/graph_main.pkl.gz` | 서울 도보 네트워크로 만든 보행 그래프 |
| `bnd/`, `tonghak/` | 집계구 경계(EPSG:5186), 초등학교 통학구역 |
| `data/` | 집계구 성·연령별 인구, 어린이 교통사고 다발지역(TAAS) |
| `corr/`, `hakgudo_students.gpkg` | 학구별 학생 수 보정 목표 |
| `gates_final.gpkg`, `q1/gates_hand.gpkg`, `gatecase_in2/` | 학교 위치점, 실제 정문 표본 31곳, 사례교 문 위치 |
| `q3/` | 사례교 로드뷰 기록 30구간 |

학생 수 보정 목표와 학교 위치점 정리(2020 위치점 + 지오코딩 48곳, 제외 5곳)는 대화형 작업으로 만들었고 결과 파일을 함께 넣었습니다.
